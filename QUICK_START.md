# Quick Start Guide - Google Pay TWIN

## 🚀 Run the App Directly

The `app.py` file is now enhanced with automatic dependency checking and installation. Simply run:

```bash
python app.py
```

## ✨ What Happens When You Run

1. **Dependency Check**: The app automatically checks for required packages
2. **Auto-Install**: Missing packages are installed automatically
3. **Launch**: Streamlit server starts and opens in your browser
4. **Access**: App runs at `http://localhost:8501`

## 📋 Features Included

- ✅ Automatic dependency management
- ✅ Error handling and user feedback
- ✅ Clean startup messages
- ✅ Graceful shutdown with Ctrl+C
- ✅ Fallback instructions if auto-install fails

## 🔧 Manual Installation (if needed)

If automatic installation fails:

```bash
pip install -r requirements.txt
python app.py
```

## 🛠️ Troubleshooting

- **"Python was not found"**: Install Python from python.org
- **Permission errors**: Run as administrator
- **Module errors**: Check internet connection for auto-install
- **Port conflicts**: Streamlit will find an available port
